Basic operators are foundational symbols or keywords used in programming languages to perform calculations, compare values, and control logic. 

The table below summarizes the most common categories of basic programming operators:

## 📊 Table of Basic Programming Operators

| Category | Operator | Symbol(s) | Description | Example (let `x` be `10` and `y` be `3`) |
|:--|:--|:--|:--|:--|
| Arithmetic | Addition | `+` | Adds two values | `x + y` → `13` |
| | Subtraction | `-` | Subtracts the right value from the left | `x - y` → `7` |
| | Multiplication | `*` | Multiplies two values | `x * y` → `30` |
| | Division | `/` | Divides the left value by the right | `x / y` → `3.3333333333` |
| | Modulus (Remainder) | `%` | Returns the remainder of a division | `x % y` → `1` |
| Comparison / Relational | Equal to | `==` | Checks if two values are equal | `x == y` → `false` |
| | Not equal to | `!=` | Checks if two values are not equal | `x != y` → `true` |
| | Greater than | `>` | Checks if left is greater than right | `x > y` → `true` |
| | Less than | `<` | Checks if left is less than right | `x < y` → `false` |
| | Greater than or equal to | `>=` | Checks if left is greater or equal | `x >= 10` → `true` |
| | Less than or equal to | `<=` | Checks if left is less or equal | `x <= y` → `false` |
| Logical | Logical AND | `&&` | Returns true if both conditions are true | `(x > 5) && (y < 5)` → `true` |
| | Logical OR | `\|\|` | Returns true if at least one condition is true | `(x < 5) \|\| (y < 5)` → `true` |
| | Logical NOT | `!` | Inverts the boolean value (turns true to false) | `!(x == y)` → `true` |
